# Desarrollo manual de my_harness

Lee y aplica `AGENTS.md` como contrato compartido de este repositorio. Después consulta `docs/STATE.md` y `docs/NEXT_STEPS.md`.

En este repositorio puedes analizar, implementar y revisar según la tarea del usuario. El reparto Codex revisor / Claude ejecutor describe el producto que estamos construyendo; no limita las sesiones manuales de desarrollo.

No ejecutes el harness de ReferenceProject ni coordines otros agentes automáticamente. Mantén las decisiones y el estado en los documentos compartidos para que el usuario pueda alternar entre Codex y Claude Code.
