First public release of My Harness: a local application that runs a development harness with AI coding agents
(Codex CLI and Claude Code) over your own Git repositories. Tested on macOS on Apple silicon only.

## Install

Download both assets into the same folder, then:

```sh
shasum -a 256 -c my-harness-0.1.0-distribution.tar.gz.sha256
tar -xzf my-harness-0.1.0-distribution.tar.gz
cd my-harness-0.1.0
scripts/install --dist "$PWD" --allow-network
scripts/start
```

The package needs Python 3.14, uv 0.12.19 and Git (no Node/npm). To install from source instead, follow the
[README](https://github.com/AcostaDDev/my-harness#install). See the [changelog](https://github.com/AcostaDDev/my-harness/blob/main/CHANGELOG.md)
for what is included and the known limits.

## Assets

- `my-harness-0.1.0-distribution.tar.gz`: self-contained package (wheel with the compiled UI, sdist, `pylock.toml`,
  `distribution-1.json`, `SHA256SUMS` and the `scripts/` installer).
- `my-harness-0.1.0-distribution.tar.gz.sha256`: checksum of the archive.
